Journal de trading institutionnel · Heatmap gamma exposure S&P 500 & Nasdaq (données CBOE)

🖥️ Installer sur le Bureau (recommandé)

Installation 100 % automatique : installe Python si besoin, place l'application sur votre Bureau avec un raccourci, et la lance. En mode local, votre PC prend lui-même les snapshots d'options toutes les 30 minutes.

⬇️ Installer l'application
1
Cliquez sur le bouton — le fichier Installer-Trading-Journal.bat se télécharge. Si le navigateur demande, choisissez « Conserver ».
2
Ouvrez le fichier téléchargé. Si Windows affiche « Windows a protégé votre PC », cliquez Informations complémentaires → Exécuter quand même (fenêtre normale pour un fichier non signé).
3
C'est tout : l'installateur fait le reste et l'application s'ouvre toute seule.
🌐 Ou installer la version web (sans téléchargement)

La même application, dans sa propre fenêtre avec une icône sur le Bureau et le menu Démarrer. Les données sont mises à jour automatiquement dans le cloud, même PC éteint.

Si rien ne se passe : dans Chrome ou Edge, cliquez sur l'icône « Installer l'application » à droite de la barre d'adresse (ou menu ⋮ → « Caster, enregistrer et partager » → « Installer la page »).
