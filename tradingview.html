📈 GEX Levels ES/NQ — pour vos futures mini & micro

L'indicateur reconnaît tout seul le marché du graphique (ES, MES → S&P 500 · NQ, MNQ → Nasdaq 100) et trace les niveaux GEX calculés sur les options SPX/NDX : call wall, put wall, gamma flip, murs 0DTE et strikes majeurs — convertis en prix futures en temps réel par TradingView. Les niveaux sont recalculés automatiquement toutes les 30 min en séance.

⚙️ Installation (une seule fois)
1
Cliquez « Copier l'indicateur » ci-dessus.
2
Dans TradingView, ouvrez le Pine Editor (onglet en bas de l'écran) → menu du script → Créer un nouveau → Indicateur.
3
Sélectionnez tout le code existant (Ctrl+A), collez (Ctrl+V), puis Enregistrer (nommez-le « GEX ES/NQ ») et Ajouter au graphique.
4
C'est prêt sur ES, MES, NQ et MNQ — changez de symbole, l'indicateur s'adapte tout seul.
🔄 Mise à jour des niveaux

TradingView interdit aux indicateurs d'accéder à internet : aucun script ne peut télécharger des données d'options lui-même. Pour actualiser, revenez ici, Copier, puis dans le Pine Editor du script Ctrl+A → Ctrl+V → Enregistrer — le graphique se met à jour instantanément. L'open interest n'étant publié qu'une fois par jour (OCC, avant l'ouverture), une mise à jour vers 9h00 New York (15h00 Paris) suffit pour les murs ; recopiez en cours de séance pour suivre le déplacement du gamma flip. Le tableau de l'indicateur affiche l'âge des données et passe au rouge quand elles sont périmées.

🎯 Niveaux embarqués dans la version actuelle

Niveaux exprimés en points de l'indice. Dans TradingView, ils sont convertis en prix ES/NQ via la base live (ratio futures / indice).

🔔 Alertes incluses

Dans TradingView : Alerte → Condition : GEX ES/NQ → « Croisement du gamma flip », « Test du call wall » ou « Test du put wall ».
